# 🏥 Aarogya Vault

A modern and user-friendly digital healthcare platform designed to simplify the management and accessibility of personal health information.

The platform provides a centralized interface for managing ABHA-related services, health records, consent, emergency information, and medical history.

---

## 🌟 Features

### 🆔 ABHA Management

* Create an ABHA account
* Link an existing ABHA account
* Check ABHA status

### 🔐 Secure Access

* User login functionality
* OTP verification
* QR-based access

### 📋 Health Records

* View and manage health information
* Digital health vault
* Individual health record viewing
* Doctor history

### 🤝 Consent Management

* Manage consent for sharing health information
* Provide users with greater control over their healthcare data

### 🚨 Emergency Profile

* Quick access to important medical information during emergencies

### 🌐 Language Support

* Language selection functionality for improved accessibility

## 💡 How It Works

1. The user accesses the application through the landing page.
2. The user logs in and verifies their identity using OTP.
3. The user can access ABHA-related services.
4. Health records can be managed through the digital vault.
5. Users can manage consent for sharing their health information.
6. Emergency information can be accessed when required.
7. Additional features such as QR access and doctor history improve the overall healthcare experience.

---

## 🎯 Project Objective

The objective of this project is to create a simple and accessible digital healthcare interface that brings important health-related services together in one place.

The platform focuses on:

* Improving accessibility to health information
* Providing centralized health record management
* Giving users control over data sharing through consent
* Supporting quick access to emergency medical information
* Creating a simple and intuitive user experience
